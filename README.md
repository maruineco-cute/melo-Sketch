# メロスケッチ 🎨🎵

**絵と音を、ひとつの作品に。**

自由に絵を描き、その絵に音楽を添えて、画像や音付き動画として保存・シェアするアプリです。スマートフォンの指操作と、パソコンのマウス・ペン操作に対応しています。

## まず知っておくこと

- **GitHub Pagesで公開するなら、`index.html` だけでアプリが動きます。**
- スタイル・プログラム・録音音源は、すべてHTMLに含まれています。音源フォルダや追加ライブラリのアップロードは不要です。
- 最初は空のキャンバスです。サンプルの絵が勝手に入ることはありません。
- **作品の自動保存はありません。** 再読み込みやタブを閉じる前に、画像・動画を保存してください。
- PNG／JPGは絵だけの保存です。音楽も残したい場合は「投稿・シェア」から動画を作成してください。

## 同梱ファイル

| ファイル | 用途 |
|---|---|
| `index.html` | 最新版のアプリ本体。GitHub Pagesのトップページになります。 |
| `README.md` | この説明書。 |
| `AUDIO_CREDITS.md` | 録音音源の出典・利用条件・加工内容。 |
| `server.py` | **任意**。音付き動画をH.264／AACのMP4へ変換するサーバー。GitHub Pagesでは実行されません。 |
| `.gitignore` | 開発用・一時ファイルをGitの対象から外す設定。 |

## GitHub Pagesで公開する

1. ZIPを解凍します。
2. 解凍したフォルダの**中身**を、GitHubリポジトリの直下にアップロードします。
   - `index.html` がリポジトリ直下にある状態にしてください。
   - ZIPそのものをアップロードしても、アプリのページにはなりません。
   - `server.py` はGitHub Pagesに不要です。アップロードを省いても問題ありません。
3. リポジトリの **Settings → Pages** を開きます。
4. **Source：Deploy from a branch** を選びます。
5. **Branch：main / フォルダ：`/(root)`** を選び、Saveします。
6. 公開が完了したら、表示されたHTTPSのURLを開きます。

スマートフォンでは、公開URLをSafariやChromeで開いてください。スマホのファイルアプリのプレビューでは、音声・保存・共有に制限がある場合があります。

> Pagesの画面や利用条件は、GitHubの変更やアカウントのプランによって異なる場合があります。公開リポジトリを使う方法が簡単です。

## 使い方

### 1. 音色と色を選ぶ

音色は次の5種類です。

| 音色 | 音の仕組み |
|---|---|
| マリンバ | 実際の楽器を録音した9音のサンプル。 |
| ピアノ | グランドピアノのステレオ録音。9音×2段階の強弱を使用。 |
| ビブラフォン | 実録音。ノイズ低減と、静かに消える減衰処理済み。 |
| リズム | キック・スネア・ハイハットを音響合成。低音には、小さなスピーカーでも聞き取りやすい成分を追加。 |
| ピコピコ | ゲーム風の電子音。矩形波を使った短い音です。 |

音色を押すと試聴できます。音を鳴らすには、最初に画面をタップする必要があります。

色は、普段使う**6色**と追加色ボタンです。追加色の**「＋」を押したときだけ24色**が開きます。色と音色は別々に選べます。

スマホでは、上部のツールバーを横にスワイプすると、色・ブラシ・背景などのツールが見られます。

### 2. 自由に描く

- ブラシ：**光／インク**。
- 消しゴム：**太さ10固定**。消した箇所に対応する音も、次の再生から鳴らなくなります。
- 「↶ 戻す」で、最後の描画や消しゴム操作を戻せます。
- 「クリア」で、絵・作品名・音・発光・保存プレビューをリセットします。背景の選択は残ります。
- 描画中の文字選択や長押しメニューを抑制しています。作品名の入力欄だけは文字を選択・編集できます。

**音程は上下、再生のタイミングは左右**で決まります。絵の形自体は変えず、音だけを音階・拍に整理します。

「描画41回」などの表示は、線や点の描画履歴の数です。指やマウスを置いてから離すまでを1回として数えます。消しゴム操作はこの数に含めません。この表示は保存画像・動画には入りません。

### 3. 絵を聴く

「▶ 絵を聴く」で、描いた絵が繰り返し演奏されます。音が鳴る箇所が光ります。

- ビート：ON／OFFを切り替えられます。
- 速度：90／112／132 BPM。
- 和音：最初はOFFです。ONにすると、同じ音色で同じタイミングに重なる線を**最大3音**で鳴らします。
- 和音では、近すぎる音程を避けて音を整理します。和音OFFでは、同じ音色・同じタイミングの最後の線を優先します。

描く回数の設定上限はありません。ただし、描く量が非常に多い場合は端末によって動作が重くなります。すべての線を無制限に同時発音する方式ではありません。

### 4. 保存・シェアする

#### 絵だけを保存

「絵を保存」→ **PNG／JPG** を選択 →「保存する」または共有ボタン。

- 幅1080pxの画像です。
- 選んだ形に応じて、4:5／1:1／9:16で出力します。
- 絵・背景・入力した作品名だけを保存します。操作ボタンや描画回数は入りません。
- PNGは画像の劣化がない形式、JPGは一般的な投稿先で扱いやすい形式です。
- JPGは高めの画質設定で出力します。
- 保存した画像から、元の線・音の編集状態を復元する機能はありません。

#### 絵と音楽を動画にする

「投稿・シェア」→ 動画を作成 →「投稿先を選ぶ」または「保存して投稿」。

- 絵・発光・音楽を**2ループ分＋短い余韻**収録します。112 BPMの場合は約10秒です。
- 操作画面は収録しません。
- 収録・作成中は、この画面を開いたままにしてください。
- 対応したスマホ・ブラウザでは、OSの共有メニューから投稿先を選べます。
- 共有に対応しない環境ではファイル保存に切り替わります。保存した作品を投稿アプリで選んでください。
- **SNSへの直接自動投稿は行いません。** 投稿先で内容を確認してから、自分で投稿します。

### 動画形式について：重要

| 公開方法 | 動画の保存形式 |
|---|---|
| GitHub Pagesなどの静的サイト | ブラウザが対応するMP4またはWebM。MP4でも音声コーデックによって投稿先で読み込めない場合があります。 |
| 同梱の変換サーバーを使用 | **H.264映像＋AAC音声のMP4**へ変換します。 |

**GitHub PagesはPythonやFFmpegを実行できません。** PNG／JPG保存やブラウザ内の録画は利用できますが、サーバーによる互換MP4への変換には別のホスティングが必要です。

静的サイト版では変換APIを呼びません。音声・描画・画像作成・録画はブラウザ内で処理します。

## 任意：MP4変換サーバーを使う

通常のGitHub Pages公開には不要です。投稿向けのH.264／AAC形式へ自動変換したい場合だけ使ってください。

### 必要なもの

- Python 3
- FFmpeg（`ffmpeg` コマンドが使えること。H.264／AACのエンコーダーが必要です。）
- Pythonの外部パッケージは不要です。

FFmpegの導入例：

```bash
# Ubuntu / Debian
sudo apt-get update
sudo apt-get install ffmpeg

# macOS（Homebrewを導入済みの場合）
brew install ffmpeg
```

起動：

```bash
cd melosketch
python3 server.py
```

Windowsでは、環境により `python server.py` または `py server.py` を使います。

パソコンのブラウザで `http://localhost:8080/` を開きます。

サーバーが配信するページだけ、動画の変換機能が有効になります。通常の`index.html`やGitHub Pagesでは無効です。

- サーバーは`0.0.0.0:8080`で待ち受けます。
- 変換時は、録画した動画がこのサーバーに送られます。
- 作業用動画は一時フォルダに置き、変換終了後に削除します。
- 変換は最大40MB・最長90秒に制限しています。
- 外部から利用する場合はHTTPSを設定してください。共有機能は安全なコンテキストなど、ブラウザの条件に依存します。
- 同梱サーバーはローカル利用・試作向けです。認証・利用者ごとの制限・レート制限はありません。不特定多数向けの公開サーバーにする場合は、別途対策が必要です。

## ブラウザ・よくある質問

### スマホでも使えますか？

はい。新しいSafariやChromeを想定しています。公開したHTTPSのURLで開く方法をおすすめします。古いOSやブラウザでは録画・共有が利用できない場合があります。

### 音が出ません

- 音色ボタンをタップして、音声を開始してください。
- メディア音量や出力先（Bluetoothイヤホン等）を確認してください。
- ファイルアプリのプレビューではなく、Safari／Chromeで開いてください。
- 別のタブや画面から戻った場合は、再度再生してください。

### 動画作成が重いです

描く量や端末の性能によって負荷が変わります。ほかのタブを閉じたり、描画量を減らしたりして試してください。画像保存は録画より負荷が小さくなります。

### 描画中に文字が選択されます

最新版には文字選択・長押しメニューの防止処理が入っています。古い版を開いていないか確認し、ページを再読み込みしてください。作品名の入力欄は編集可能です。
